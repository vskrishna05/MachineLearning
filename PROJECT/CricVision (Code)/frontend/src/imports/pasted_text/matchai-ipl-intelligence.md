============================================================
1. CORE PRODUCT PURPOSE
============================================================

MATCHAI analyzes historical IPL match data and uses machine-learning models to estimate the outcome of a selected match.

The system uses:

- Logistic Regression
- Random Forest
- Elo Rating
- Historical Win Rate
- Recent Form
- Average Runs
- Average Wickets
- Run Rate
- Head-to-Head Performance

The current primary model is Logistic Regression.

The current evaluated Logistic Regression performance is:

Accuracy: 55.94%
ROC-AUC: 0.5364

Do NOT display unrealistic claims such as 90%, 95%, or "guaranteed prediction".

The product should clearly communicate that MATCHAI provides a statistical machine-learning prediction, not a guaranteed match result.
